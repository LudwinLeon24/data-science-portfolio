# Used Car Price Prediction – Rusty Bargain

This project was developed as part of a Data Science training program. The goal was to build and compare different machine learning models to predict the market value of used vehicles for Rusty Bargain, a company looking to implement a car valuation feature in their upcoming app.

## Project Objectives

To train and evaluate machine learning models that can accurately predict the price of a used car based on its features, while also considering:

Prediction quality (RMSE)

Speed of prediction

Training time

## Tools and Technologies
Python 
Pandas
Scikit-learn
LightGBM
CatBoost
RandomForest (from sklearn)
Jupyter Notebook

## Models Tested

- **Linear Regression**
- **Random Forest Regressor**
- **Catboost**
- **LightGBM**  *(best performing model)*

After comparing different models, **LightGBM** was selected due to its superior performance and efficiency.

## Evaluation Metric

- **RMSE (Root Mean Squared Error)** was used as the main metric to evaluate prediction accuracy.
